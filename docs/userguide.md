## Patron Guide

### Sign Up
- Click **"Sign Up"** button.

  <p align="center">
    <img src="images/user_guide/blank_login.png" width="500"/>
  </p>

- Input email, password, password confirmation, first name, and last name. Click **"Submit"**.

  <p align="center">
    <img src="images/user_guide/sign_up.png" width="500"/>
  </p>

- Return to the previous page, or click **"Login"** to log in.

  <p align="center">
    <img src="images/user_guide/login.png" width="500"/>
  </p>

### Home Page
- After logging in, you will be greeted with this page.

  <p align="center">
    <img src="images/user_guide/patron_home.png" width="1000"/>
  </p>

- Here, you can search for books using the provided search bar and an optional filter.

  <p align="center">
    <img src="images/user_guide/patron_home_search.png" width="1000"/>
  </p>

- Click the **"View Details"** button under a search result to view more details, and **"Reserve Now!"** to reserve the title to check out later in person.

  <p align="center">
    <img src="images/user_guide/patron_home_book_details.png" width="600"/>
  </p>
